وعد النظام

كل خدمة ترخيص لها مسار، وكل قرار له أثر.

يعرض DVLD جوهر النظام كما يحتاجه موظف الترخيص: خدمة واضحة، قواعد تحقق قبل القرار، بيانات مركزية، صلاحيات مضبوطة، وسجل حركة يحفظ كل خطوة.

هوية غير مكررة شروط قبل الإصدار تتبع وتراجع

دورة الطلب

رحلة واحدة، لكنها لا تسمح بتجاوز خطوة ناقصة.

من الرقم الوطني وحتى إصدار الرخصة، يحافظ النظام على تسلسل القرار: لا طلب مكرر، لا رخصة من نفس الفئة، ولا انتقال للاختبار التالي قبل نجاح السابق.

مرحلة نشطة

ملف شخص واحد يمنع فوضى التكرار قبل أن تبدأ.

يبدأ النظام من الرقم الوطني. إن لم يكن الشخص موجودًا، تتم إضافته أولًا مع بياناته الأساسية وصورته، ثم ترتبط كل الطلبات والرخص المستقبلية بهذا السجل.

  • بحث بالرقم الوطني قبل إنشاء أي طلب جديد.
  • حفظ الاسم الرباعي والميلاد والجنسية والتواصل والصورة.
  • منع تكرار الشخص نفسه داخل قاعدة البيانات.

الخدمات

سبع خدمات ليست أزرارًا منفصلة، بل حالات داخل منظومة واحدة.

كل خدمة تملك شروط قبول ورسومًا وحالة طلب، وتُبقي أثر الحركة محفوظًا للمراجعة التشغيلية والإدارية.

رخصة دولية

بوابة الاختبارات

ثلاثة اختبارات، وترتيبها جزء من سلامة القرار.

لا يكتفي النظام بحفظ النتيجة؛ بل يحفظ الموعد والرسوم والنجاح أو الرسوب، ويمنع متابعة المسار عند فشل المرحلة السابقة.

فئات الرخص

فئة الرخصة تحدد العمر والرسوم ومدة الصلاحية.

صممت الفئات كمرجع قابل للتعديل في النظام: الاسم والوصف ثابتان، بينما يمكن ضبط العمر والمدة والرسوم حسب السياسة المعتمدة.

البنية البرمجية

مشروع WinForms لكن بمنطق طبقات واضح خلف الشاشة.

صُمم DVLD بروح الطبقات التشغيلية: واجهة تخدم الموظف، منطق أعمال يحكم الشروط، طبقة بيانات تحفظ السجلات، وقاعدة SQL Server تجعل القرارات قابلة للتتبع والمراجعة.

DVLD

واجهة المستخدم وإدارة شاشات الخدمات، الأشخاص، المستخدمين، الطلبات، الاختبارات، والرخص.

DVLD_Buisness

طبقة منطق الأعمال: شروط القبول، حالات الطلب، ربط الرخص بالسائقين، وإدارة نتائج الخدمات.

DVLD_DataAccess

طبقة الوصول للبيانات، حيث تتحول القرارات التشغيلية إلى استعلامات وإجراءات منظمة.

SQL Server

قاعدة بيانات تحفظ الأشخاص والطلبات والرخص والاختبارات والمستخدمين وسجل الحركات.

غرفة العمليات

لقطة تشغيلية من داخل دائرة الترخيص.

هذه الواجهة المصغرة تلخص طريقة تفكير النظام: طلبات بحاجة قرار، رخص محجوزة، اختبارات اليوم، وحركة مستخدمين محفوظة للتدقيق.
