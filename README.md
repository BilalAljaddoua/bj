# Bilal Aljaddoua Portfolio - HTML/CSS/JS

This is the standalone static version of the portfolio.

## Files

- `index.html`: the website page.
- `styles.css`: all styling.
- `script.js`: language toggle, theme toggle, menu, FAQ, project details, and contact form behavior.
- `assets/`: CV files, icon, and visual assets.
- `projects/`: attached project PDF files.

## Run

Open `index.html` directly in a browser, or serve the folder with any static server.
